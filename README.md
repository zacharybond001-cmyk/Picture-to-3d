# Picture to 3D

Turn pictures into 3D-printable models: lithophanes, reliefs, logo signs, multicolor 3MF, layer-color (HueForge-style) prints and cookie cutters. No AI. Runs entirely in the browser, works offline once installed.

**Open / install:** https://zacharybond001-cmyk.github.io/Picture-to-3d/

- Android: Chrome → ⋮ → Add to Home screen → Install
- Linux/Windows/Mac: Chrome or Edge → install icon in the address bar
